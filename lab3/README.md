# LAB CHƯƠNG 3 – CANNY EDGE DETECTOR

## Cấu trúc

```text
lab3/
├── input/
│   └── anh_mau_lab3.png
├── results/
├── Lab_Chuong_3_Canny.ipynb
├── requirements.txt
└── README.md
```

## Cách chạy

1. Mở terminal tại thư mục `lab3`.
2. Cài thư viện: `pip install -r requirements.txt`.
3. Mở Jupyter Notebook: `jupyter notebook`.
4. Mở `Lab_Chuong_3_Canny.ipynb` và chọn **Run All**.
5. Kết quả ảnh và bảng tổng hợp được lưu trong `results/`.

## Dùng ảnh riêng

- Chép ảnh vào thư mục `input/`.
- Mở notebook, đến phần **1. Đọc ảnh do người dùng cung cấp**.
- Đổi `IMAGE_FILENAME = "anh_mau_lab3.png"` thành tên ảnh của bạn.
- Chạy lại notebook từ đầu.

Ảnh mẫu được cung cấp để notebook có thể chạy thử ngay. Các ảnh nhiễu, tương phản thấp và nhiều chi tiết được tạo từ ảnh đầu vào để so sánh có kiểm soát.
